# 구형 모바일기기 사용 규정

> 이 문서는 2025년 4월 30일 효력이 종료되었으며 [모바일기기 보안 규정](REG-000019.md)으로 대체되었다.

## 제1조 적용 대상

업무용으로 지급된 스마트폰과 태블릿에 적용한다.

## 제2조 잠금 설정

사용자는 화면 잠금과 원격 삭제 기능을 활성화해야 한다.

## 제3조 분실 신고

기기를 분실하면 발견 즉시 부서장과 정보보호 담당자에게 알린다.
