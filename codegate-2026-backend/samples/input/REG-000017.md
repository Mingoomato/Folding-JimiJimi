# 클라우드 서비스 이용 규정

## 제1조 도입 승인

클라우드 서비스 도입 전 데이터 종류, 저장 위치, 관리자 권한, 계약 종료 시 데이터 반환 방법을 검토한다.

## 제2조 책임 공유

서비스 제공자의 보호조치와 조직이 직접 수행해야 하는 설정을 구분하여 문서화한다.

## 제3조 종료 절차

서비스 종료 시 다음을 확인한다.

1. 필요한 데이터의 안전한 반출
2. 사용자와 관리자 계정 제거
3. 연동 키와 토큰 폐기
4. 제공자 측 데이터 삭제 확인

설정 점검은 [클라우드 보안점검 매뉴얼](MAN-000009.md)을 따른다.
