# 의심 전자우편 대응 매뉴얼

## 1. 열기 전

발신자 표시명만 믿지 말고 실제 주소, 링크 대상, 긴급성을 과도하게 강조하는 표현을 확인한다.

## 2. 링크나 첨부파일을 실행한 경우

1. 네트워크 연결을 중지한다.
2. 기기를 종료하거나 파일을 삭제하기 전에 보안 담당자에게 연락한다.
3. 실행 시각과 수행한 동작을 설명한다.
4. 요구받기 전까지 비밀번호를 임의로 변경하지 않는다.[^1]

[^1]: 사고 분석 과정에서 변경 순서가 중요할 수 있다.

## 3. 신고 정보

원본 메시지를 첨부 방식으로 전달하고 화면 캡처만 보내지 않는다. 상위 기준은 [전자우편 및 메신저 사용 규정](REG-000016.md)이다.
