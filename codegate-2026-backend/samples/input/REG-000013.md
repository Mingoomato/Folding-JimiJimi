# 암호화 및 암호키 관리 규정

## 제1조 암호화 적용

기밀정보와 인증정보는 승인된 암호기술을 사용하여 저장 및 전송한다. 자체 제작 암호 알고리즘은 사용하지 않는다.

## 제2조 키 수명주기

암호키는 생성, 등록, 배포, 보관, 교체, 폐기 단계를 추적할 수 있어야 한다.

| 구분 | 요구사항 |
|---|---|
| 생성 | 승인된 난수 생성기 사용 |
| 보관 | 데이터와 분리된 위치에 저장 |
| 교체 | 노출 의심 또는 유효기간 만료 시 수행 |
| 폐기 | 복구할 수 없는 방식으로 제거 |

실무 절차는 [암호키 운영 매뉴얼](MAN-000008.md)에 따른다.
