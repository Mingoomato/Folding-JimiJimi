# 생성형 AI 안전 이용 가이드 초안

> 검토 중인 문서이며 공식 운영 지침이 아니다.

## 1. 입력 전 확인

입력하려는 내용을 공개, 내부, 기밀로 구분하고 서비스가 해당 등급을 처리하도록 승인되었는지 확인한다.

## 2. 출력 검토

- 사실과 숫자를 원문에서 다시 확인한다.
- 존재하지 않는 출처가 생성되지 않았는지 확인한다.
- 개인정보와 비밀정보가 출력에 섞이지 않았는지 확인한다.
- 중요한 결정은 생성 결과만으로 내리지 않는다.

## 3. 기록

중요 업무에 사용한 경우 사용 목적, 검토자 및 최종 판단 근거를 남긴다. 상위 초안은 [생성형 AI 업무 이용 규정 초안](REG-000020.md)이다.
