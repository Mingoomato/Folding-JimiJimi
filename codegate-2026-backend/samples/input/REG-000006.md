# 원격근무 보안 규정

## 제1조 허용 환경

원격근무는 조직이 승인한 단말과 접속 수단을 이용해야 한다. 공용 PC와 출처를 알 수 없는 무선망은 사용하지 않는다.

## 제2조 준수사항

- 화면 잠금을 설정한다.
- 가족 등 제3자와 업무 단말을 공유하지 않는다.
- 출력물과 메모를 방치하지 않는다.
- 업무 종료 후 원격접속을 종료한다.

## 제3조 사고 보고

단말 분실, 계정 노출 또는 비정상 접속이 의심되면 네트워크 연결을 중지하고 보안 담당자에게 즉시 보고한다.
