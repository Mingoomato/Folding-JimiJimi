# 구형 VPN 접속 매뉴얼

> 이 매뉴얼은 더 이상 사용하지 않는 접속 방식에 대한 기록이다. 현재 원격접속 절차로 사용해서는 안 된다.

## 1. 과거 적용 범위

2023년부터 2025년까지 운영된 레거시 VPN 클라이언트에 적용되었다.

## 2. 보관 목적

과거 장애와 접속 기록을 해석해야 하는 경우에만 참조한다. 신규 설치나 설정에는 적용하지 않는다.

현재의 보안 원칙은 [원격근무 보안 규정](REG-000006.md)을 확인한다.
