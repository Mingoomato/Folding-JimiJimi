# 개인정보 처리 규정

## 제1조 처리 원칙

개인정보는 명확한 목적에 필요한 최소 범위에서 수집하고, 목적이 달성되면 보유기간에 따라 파기한다.

## 제2조 처리 단계

1. 수집 목적과 법적 근거를 확인한다.
2. 개인정보 항목과 보유기간을 등록한다.
3. 접근 가능한 담당자를 최소화한다.
4. 제공 또는 위탁 내역을 기록한다.

> 주민등록번호와 같은 고유식별정보는 일반 개인정보와 분리하여 보호해야 한다.

## 제3조 정보주체 요청

열람, 정정, 삭제 및 처리정지 요청은 접수일로부터 내부 처리기한 안에 회신한다. 세부 절차는 [개인정보 요청 처리 매뉴얼](MAN-000002.md)을 따른다.
