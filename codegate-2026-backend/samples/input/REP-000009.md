# 모바일기기 분실사고 분석 보고서

## 1. 개요

직원이 이동 중 업무용 스마트폰을 분실했다. 분실 인지 12분 후 신고했고 원격 잠금은 신고 6분 뒤 수행되었다.

## 2. 영향 분석

기기는 암호화와 화면 잠금이 적용되어 있었고 업무 앱은 추가 인증을 요구했다. 조사 범위에서 무단 접속 흔적은 확인되지 않았다.

## 3. 개선사항

해외 출장자에게 제공되는 신고 연락처를 한 페이지로 정리하고 잠금화면에도 표시하기로 했다. 현재 통제 기준은 [모바일기기 보안 규정](REG-000019.md)이다.
