# 보안 로그 분석 매뉴얼

## 1. 분석 준비

분석 시각 범위와 시스템 시간대를 확인한다. 서로 다른 시스템의 로그를 결합할 때는 기준 시간을 통일한다.

## 2. 기본 질의 예시

```sql
SELECT actor, action, result, occurred_at
FROM audit_log
WHERE result = 'failure'
ORDER BY occurred_at DESC;
```

예시는 데이터 구조를 설명하기 위한 것이며 실제 운영 데이터베이스에서 직접 실행하기 전에 권한과 부하를 확인한다.

## 3. 이상 징후

짧은 시간의 반복 실패, 사용하지 않던 지역의 접속, 업무시간 외 특권 변경을 우선 확인한다. 사고가 의심되면 [정보보호 사고 대응 규정](REG-000009.md)을 적용한다.
