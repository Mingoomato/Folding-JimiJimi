# 생성형 AI 업무 이용 규정 초안

> 검토 중인 초안으로 아직 효력이 없다.

## 제1조 허용 원칙

승인된 서비스와 계정을 사용하며 입력하려는 정보의 등급과 서비스의 데이터 처리 조건을 사전에 확인한다.

## 제2조 금지사항

- 비밀번호, 비밀키 및 인증 토큰 입력
- 승인되지 않은 서비스에 기밀정보 입력
- 생성 결과를 검증 없이 의사결정 근거로 사용
- 타인의 저작물이나 개인정보를 목적 없이 입력

## 제3조 결과 검토

사용자는 생성 결과의 정확성, 편향, 출처 및 보안 영향을 확인하고 최종 산출물에 대한 책임을 진다.
