# 외부 협력사 보안관리 규정

## 제1조 사전 평가

중요 정보 또는 시스템에 접근하는 협력사는 계약 전에 보안 수준과 사고 대응 능력을 평가받아야 한다.

## 제2조 계약 조건

계약에는 다음 조건을 포함한다.

1. 비밀유지 의무
2. 접근권한 제한
3. 사고 통지 기한
4. 재위탁 제한
5. 계약 종료 시 정보 반환 또는 파기

## 제3조 종료 확인

업무 담당자는 계약 종료 후 계정 회수와 자료 파기 증빙을 확인한다. 점검 방법은 [협력사 보안점검 매뉴얼](MAN-000004.md)을 참고한다.
