# 업무용 모바일기기 설정 매뉴얼

## 1. 등록 전 확인

자산번호, 사용자, 기기 식별정보 및 운영체제 지원 여부를 확인한다.

## 2. 기본 설정

- 화면 잠금과 자동 잠금시간 설정
- 저장공간 암호화 확인
- 기기관리 프로파일 등록
- 원격 잠금 및 삭제 활성화
- 승인된 업무 앱 설치

## 3. 사용자 인계

사용자에게 분실 신고 방법, 금지 앱, 백업 범위 및 해외 사용 시 주의사항을 안내한다.

적용 기준은 [모바일기기 보안 규정](REG-000019.md)이다.
