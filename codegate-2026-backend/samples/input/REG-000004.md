# 정보자산 분류 규정

## 제1조 분류 등급

정보자산은 영향도에 따라 다음과 같이 분류한다.

| 등급 | 설명 | 예시 |
|---|---|---|
| 공개 | 외부 공개가 승인된 정보 | 보도자료 |
| 내부 | 조직 내부에서 사용하는 정보 | 업무 지침 |
| 기밀 | 유출 시 중대한 피해가 발생하는 정보 | 인증정보, 핵심 설계자료 |

## 제2조 표시

문서 작성자는 제목 또는 문서 속성에 분류 등급을 표시한다. 등급이 불분명하면 자산 소유자에게 확인한다.

## 제3조 재분류

자산 소유자는 매년 등급의 적정성을 검토하고 업무 목적이나 위험이 변경되면 즉시 재분류한다.
