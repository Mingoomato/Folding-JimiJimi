# 사용자 계정 운영 매뉴얼

## 1. 계정 생성

1. 승인된 계정 신청서의 사용자와 부서를 확인한다.
2. 기존 계정과 중복되는지 검색한다.
3. 기본 역할을 부여하고 임시 비밀번호를 생성한다.
4. 사용자에게 별도 채널로 초기 접속 방법을 전달한다.

## 2. 권한 변경

변경 요청의 승인자와 종료일을 확인한 후 필요한 권한만 추가한다. 기존 권한이 계속 필요한지도 함께 검토한다.

## 3. 확인 목록

- [ ] 신청자와 승인자 확인
- [ ] 최소권한 적용
- [ ] 작업 기록 저장
- [ ] 사용자 통지

상위 기준은 [계정 및 접근권한 관리 규정](REG-000002.md)이다.
