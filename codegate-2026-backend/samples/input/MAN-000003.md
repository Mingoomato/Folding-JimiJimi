# 자료 반출 운영 매뉴얼

## 1. 신청

반출 파일의 목록과 정보등급을 작성하고 수신자, 목적, 전달 수단, 회수 또는 삭제 예정일을 입력한다.

## 2. 보호조치

```text
기밀 파일 → 암호화 → 승인된 전송수단 → 비밀번호 별도 전달
```

압축파일 비밀번호를 같은 전자우편 본문에 기록하지 않는다.

## 3. 완료 확인

반출 후 수신 여부를 확인하고 만료일이 지나면 수신자의 삭제 또는 반환 여부를 확인한다.

이 매뉴얼은 [저장매체 및 문서 반출 규정](REG-000005.md)을 구현한다.
