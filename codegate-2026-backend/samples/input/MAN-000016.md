# 신규 입사자 보안설정 매뉴얼

## 1. 준비

인사정보의 입사일, 소속, 직무 및 승인자를 확인하고 표준 권한 묶음을 선택한다.

## 2. 첫 출근일

| 항목 | 완료 조건 |
|---|---|
| 계정 | 본인 확인 후 활성화 |
| 다중요소 인증 | 사용자 기기 등록 완료 |
| 단말 | 자산 등록 및 보안설정 적용 |
| 교육 | 기본 보안교육 안내 |

## 3. 사후 확인

입사 5영업일 후 과도하거나 누락된 권한이 없는지 사용자와 부서장이 확인한다.
