# 보안 코드검토 매뉴얼

## 1. 검토 범위

인증, 권한검사, 입력처리, 파일 업로드, 외부 요청, 비밀정보 처리와 감사로그 코드를 우선 검토한다.

## 2. 확인 질문

- 사용자가 소유하지 않은 객체에 접근할 수 있는가?
- 입력값이 명령어나 경로로 직접 결합되는가?
- 비밀정보가 로그나 오류 메시지에 남는가?
- 실패 시 기본적으로 접근을 거부하는가?

## 3. 결과 기록

발견 위치, 악용 조건, 영향, 수정 제안 및 검증 결과를 기록한다. 단순한 스타일 의견과 보안 결함을 구분한다.

상위 기준은 [안전한 소프트웨어 개발 규정](REG-000012.md)이다.
