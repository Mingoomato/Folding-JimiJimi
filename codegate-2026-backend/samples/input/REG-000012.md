# 안전한 소프트웨어 개발 규정

## 제1조 설계 단계

중요 기능은 인증, 권한, 데이터 흐름 및 외부 연동에 대한 보안 요구사항을 설계 단계에서 정의한다.

## 제2조 구현 단계

- 비밀정보를 소스코드에 직접 기록하지 않는다.
- 입력값을 신뢰하지 않고 검증한다.
- 오류 메시지에 내부 경로나 인증정보를 노출하지 않는다.
- 승인된 라이브러리와 버전을 사용한다.

## 제3조 배포 전 확인

코드 검토와 보안 시험에서 발견된 중대한 취약점은 배포 전에 조치한다. 예외 승인은 위험, 보완통제 및 종료일을 포함해야 한다.
