# 침해사고 대응 모의훈련 결과 보고서

## 1. 훈련 시나리오

관리자 계정 탈취와 외부 데이터 전송 징후가 동시에 탐지된 상황을 가정했다. 실제 운영시스템에는 영향을 주지 않는 모의 로그를 사용했다.

## 2. 측정 결과

| 지표 | 목표 | 결과 |
|---|---:|---:|
| 최초 신고 | 10분 | 7분 |
| 담당자 소집 | 20분 | 18분 |
| 영향 범위 식별 | 60분 | 74분 |

## 3. 개선사항

클라우드 로그 담당자 연락이 지연되었다. 비상연락망과 초기 분석 체크리스트를 갱신하기로 했다. 훈련 기준은 [정보보호 사고 대응 매뉴얼](MAN-000006.md)을 적용했다.
