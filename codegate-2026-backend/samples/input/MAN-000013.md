# 방문자 출입관리 매뉴얼

## 1. 사전 등록

피방문자는 방문 목적, 방문자 이름, 소속, 출입 예정시간 및 방문 구역을 등록한다.

## 2. 방문 당일

- 신분을 확인한다.
- 방문증을 눈에 보이게 착용하도록 안내한다.
- 허용된 구역만 출입하도록 동행한다.
- 촬영이나 장비 반입이 필요한 경우 별도 승인을 확인한다.

## 3. 퇴실

방문증을 회수하고 실제 퇴실 시각을 기록한다. 미반납 방문증은 즉시 비활성화한다.

관련 기준은 [물리적 보안구역 관리 규정](REG-000015.md)이다.
