# 저장매체 폐기 매뉴얼

## 1. 폐기 요청

자산번호, 매체 종류, 저장된 정보등급, 폐기 사유 및 승인자를 기록한다.

## 2. 방법 선택

| 매체 | 허용 방식 예시 |
|---|---|
| 재사용 디스크 | 검증 가능한 덮어쓰기 또는 암호키 폐기 |
| 고장 난 디스크 | 물리적 파쇄 |
| 종이 문서 | 보안 파쇄 |

## 3. 완료 확인

처리 일시, 수행자, 입회자, 사용한 방법 및 증빙을 기록하고 자산대장의 상태를 변경한다.
