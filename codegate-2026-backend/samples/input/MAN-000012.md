# 취약점 조치 및 예외처리 매뉴얼

## 1. 결과 확인

스캐너 결과만으로 조치 대상을 확정하지 않는다. 자산, 실제 버전, 노출 경로와 악용 가능성을 확인한다.

## 2. 조치

패치, 설정 변경, 기능 제거 또는 접근 제한 중 위험을 실질적으로 줄일 수 있는 방법을 선택한다.

## 3. 예외 신청

예외에는 다음 항목이 필요하다.

1. 조치할 수 없는 구체적 사유
2. 남는 위험과 영향
3. 임시 보호조치
4. 책임자와 만료일
5. 재검토 일정

위험도별 기한은 [취약점 및 보안패치 관리 규정](REG-000014.md)을 따른다.
