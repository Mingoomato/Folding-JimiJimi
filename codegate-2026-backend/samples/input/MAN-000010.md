# 데이터 백업 복구 시험 매뉴얼

## 1. 시험 계획

시험 대상, 복구 시점, 목표시간, 검증 담당자와 데이터 보호 방법을 정한다. 운영환경에 영향을 주지 않는 격리된 환경을 사용한다.

## 2. 시험 수행

백업본을 복구한 뒤 파일 수, 데이터 범위, 애플리케이션 기능 및 권한 설정을 확인한다.

## 3. 결과 기록

| 항목 | 기록 내용 |
|---|---|
| 시작·종료 | 실제 소요시간 |
| 성공 여부 | 완전·부분·실패 |
| 차이 | 목표 대비 차이와 원인 |
| 후속조치 | 책임자와 완료일 |

관련 기준은 [데이터 백업 및 복구 규정](REG-000010.md)을 따른다.
