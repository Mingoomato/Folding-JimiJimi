# 전자우편 및 메신저 사용 규정

## 제1조 업무 계정 사용

업무자료는 승인된 전자우편과 메신저를 통해 전달한다. 개인 계정이나 승인되지 않은 파일전송 서비스는 사용하지 않는다.

## 제2조 발송 전 확인

- 수신자 주소와 참조자를 확인한다.
- 첨부파일과 링크가 올바른지 확인한다.
- 기밀정보가 있으면 승인 및 보호조치를 확인한다.
- 다수 수신자에게 개인정보가 노출되지 않도록 한다.

## 제3조 의심 메시지

출처가 불분명한 링크와 첨부파일을 열지 않는다. 이미 실행했다면 네트워크를 차단하고 즉시 신고한다.
