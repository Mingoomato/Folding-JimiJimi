# 시스템 변경 작업 매뉴얼

## 1. 작업 전

- [ ] 승인번호 확인
- [ ] 영향 대상과 공지 범위 확인
- [ ] 백업 또는 복구 지점 생성
- [ ] 되돌리기 조건과 담당자 확인

## 2. 작업 중

계획된 단계별 시작·종료 시각과 결과를 기록한다. 예상하지 못한 오류가 발생하면 임의로 범위를 확대하지 않는다.

## 3. 작업 후

핵심 기능과 모니터링 상태를 확인하고 변경 결과를 승인자에게 알린다. 실패한 작업도 동일하게 기록한다.

상위 기준은 [정보시스템 변경관리 규정](REG-000011.md)이다.
