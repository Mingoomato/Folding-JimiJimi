# 개인정보 요청 처리 매뉴얼

## 1. 요청 접수

요청일, 요청 유형, 대상 정보 및 회신 방법을 기록한다. 본인 확인에 필요한 정보는 요청 처리 목적에 필요한 범위로 제한한다.

## 2. 처리 흐름

| 단계 | 담당 | 주요 확인사항 |
|---|---|---|
| 접수 | 고객지원 | 요청 내용과 연락처 |
| 검토 | 개인정보보호팀 | 법적 제한 및 본인 여부 |
| 조회 | 시스템 담당 | 대상 데이터와 보유 위치 |
| 회신 | 개인정보보호팀 | 결과 및 이의제기 방법 |

## 3. 처리 제한

제3자의 권리를 침해하거나 법령상 제한 사유가 있는 경우 근거와 가능한 대체 조치를 함께 안내한다.

관련 기준은 [개인정보 처리 규정](REG-000003.md)을 따른다.
