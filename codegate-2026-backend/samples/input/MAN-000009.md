# 클라우드 보안점검 매뉴얼

## 1. 계정과 권한

관리자 계정에 다중요소 인증이 적용되어 있는지, 장기 미사용 계정과 키가 남아 있지 않은지 확인한다.

## 2. 네트워크

| 점검항목 | 정상 기준 |
|---|---|
| 관리 포트 | 승인된 출발지에서만 접근 가능 |
| 공개 저장소 | 공개 사유와 소유자가 등록됨 |
| 방화벽 규칙 | 목적과 만료일이 기록됨 |

## 3. 로그

관리자 활동과 중요 설정 변경 로그가 중앙 저장소로 전송되는지 확인한다. 점검 결과는 예외와 함께 보관한다.

적용 기준은 [클라우드 서비스 이용 규정](REG-000017.md)이다.
