# 협력사 보안점검 매뉴얼

## 1. 점검 범위 결정

협력사가 접근하는 정보등급, 시스템 권한, 처리 인원, 재위탁 여부를 기준으로 점검 수준을 결정한다.

## 2. 필수 증빙

- 보안 담당자와 연락망
- 접근자 명단
- 보안교육 기록
- 사고대응 절차
- 계약 종료 시 자료 파기 절차

## 3. 결과 판정

중대한 미비점은 계약 또는 접근 허용 전에 보완한다. 경미한 사항은 책임자와 완료일을 지정하여 추적한다.

적용 근거는 [외부 협력사 보안관리 규정](REG-000007.md)이다.
